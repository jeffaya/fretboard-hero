Dans App Store Connect, le nom et le sous-titre se trouvent dans **Informations sur l’app**. Ouvrez ensuite la version iOS pour copier la description, le texte promotionnel, les mots-clés et les URL d’assistance et de marketing. Le champ **Nouveautés de cette version** s’utilise à partir de la première mise à jour. L’URL de la politique de confidentialité se renseigne dans **Confidentialité de l’app**.

Dans **Achats intégrés**, ouvrez le produit `lifetime_access` de l’application concernée pour y ajouter son nom et sa description dans chaque langue. L’achat ouvre les trois instruments dans l’application où il est effectué.

Les mots-clés de chaque fiche tiennent dans les 100 octets UTF-8 du champ Apple. Les noms commerciaux restent ceux des trois applications. [Langues et codes Apple](https://developer.apple.com/documentation/appstoreconnectapi/managing-metadata-in-your-app-by-using-locale-shortcodes) · [Champs de la version iOS](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/)
