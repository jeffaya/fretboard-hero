# Ukulele Fretboard Hero — Google Play — ja-JP

Fiche **日本語**, pour l’édition ukulélé. Code de langue dans l’application : `ja` ; langue de la fiche Google Play : `ja-JP`.

Traduction de la [fiche anglaise](../en-US/README.md), adaptée à l’instrument et aux termes musicaux de cette langue. Copier uniquement le contenu des trois blocs ci-dessous dans la console. Le nom de marque reste identique dans toutes les langues.

## Textes à copier-coller

### Nom de l'application — 22 / 30 caractères

```text
Ukulele Fretboard Hero
```

### Brève description — 40 / 80 caractères

```text
毎日の練習、指板クイズ、チューナーで、ウクレレの音名・スケール・コードを学ぼう。
```

### Description complète — 1068 / 4 000 caractères

```text
ウクレレの指板で迷わず弾けるように。Ukulele Fretboard Heroは、ガイド付き練習、視覚的な学習ツール、指板クイズ、チューナーをひとつにまとめたアプリです。

毎日練習する習慣を
ひとつのキーで5つの練習に取り組めます。ルート音を探し、スケールを弾き、トライアドをつなぎ、リズムを練習し、ペンタトニックのパターンをたどりましょう。タブ譜、音名、度数表示が、弾いている内容の理解を助けます。自分のペースで進め、何度でも練習を繰り返せます。

ウクレレのポジションをつなぐ
5つのペンタトニック・ポジション、メジャーとマイナーのトライアド、転回形、アルペジオ、C・A・G・Fのコードフォームを学べます。度数を強調しながら、High-GのG–C–E–Aチューニングの4本の弦でパターンをつなげましょう。

マイクのフィードバックで練習
「毎日の練習」でマイクを有効にすると、強調表示された音を追いながら、演奏に応じたフィードバックを受けられます。音やトライアドのガイド付き練習に取り組み、テンポを調整しながらリズムも練習できます。マイクをオフにしたまま練習することもできます。

クイズで理解を確認
60秒の指板クイズに挑戦。ルート、3度、5度を探し、連続正解を目指しながら、指板のさまざまな場所に慣れていきましょう。

音の位置を見つける
指板マップで4本の弦の音名を確認したり、ひとつの音だけに注目したりできます。学習ツールを切り替えながら、音名、音程、ポジションのつながりを理解しましょう。

ハーモニーを理解する
インタラクティブな五度圏で、平行短調、ダイアトニックコード、よく使われるコード進行を確認できます。キーとコードの関係を視覚的に学べます。

弾く前にチューニング
内蔵のウクレレチューナーでHigh-GのG–C–E–Aチューニングに合わせられます。弦の自動検出と手動選択に対応。音が高いか、低いか、合っているかを画面で確認できます。

無料で始める
ルート音Aの学習モードとポジション、五度圏、Aマイナーの「毎日の練習」を試せます。アプリ内で一度購入すると、このアプリのすべてのキーと音を無期限で利用できます。定期購読は不要です。

マイクとプライバシー
マイクへのアクセスは任意で、チューニングと練習中のフィードバックに使用します。音声は端末内で処理され、アプリが録音したり、サーバーへ送信したりすることはありません。

音の位置を覚え、コードフォームをつなげ、日々の練習を続けたいウクレレ奏者のために。
```
