# Ukulele Fretboard Hero — Google Play — ko-KR

Fiche **한국어**, pour l’édition ukulélé. Code de langue dans l’application : `ko` ; langue de la fiche Google Play : `ko-KR`.

Traduction de la [fiche anglaise](../en-US/README.md), adaptée à l’instrument et aux termes musicaux de cette langue. Copier uniquement le contenu des trois blocs ci-dessous dans la console. Le nom de marque reste identique dans toutes les langues.

## Textes à copier-coller

### Nom de l'application — 22 / 30 caractères

```text
Ukulele Fretboard Hero
```

### Brève description — 44 / 80 caractères

```text
매일 연습, 지판 퀴즈, 튜너로 우쿨렐레의 음 이름, 스케일, 코드를 익히세요.
```

### Description complète — 1174 / 4 000 caractères

```text
우쿨렐레 지판에서 음의 위치를 익혀 보세요. Ukulele Fretboard Hero는 가이드 연습, 시각적 학습 도구, 지판 퀴즈, 튜너를 하나의 앱에 담았습니다.

매일 연습하는 습관 만들기
하나의 조성에서 다섯 가지 연습을 진행하세요. 근음을 찾고, 스케일을 연주하고, 트라이어드를 연결하고, 리듬을 연습하고, 펜타토닉 패턴을 탐색할 수 있습니다. 타브 악보, 음 이름, 도수 표시가 연주 내용을 이해하도록 도와줍니다. 자신의 속도에 맞춰 진행하고 루틴을 반복해 보세요.

우쿨렐레 포지션 연결하기
다섯 가지 펜타토닉 포지션, 메이저와 마이너 트라이어드, 전위, 아르페지오, C·A·G·F 코드 폼을 살펴보세요. 원하는 도수를 강조하고, 높은 G현을 사용하는 G–C–E–A 튜닝의 네 줄에서 패턴을 연결할 수 있습니다.

마이크 피드백과 함께 연주하기
매일 연습에서 마이크를 켜면 강조된 음을 따라 연주하며 피드백을 받을 수 있습니다. 음과 트라이어드 가이드 연습을 따라 하고, 템포를 조절하며 리듬을 연습하세요. 마이크를 끈 상태에서도 연습할 수 있습니다.

퀴즈로 실력 확인하기
60초 지판 퀴즈에 도전하세요. 근음, 3도, 5도를 찾고 연속 정답을 쌓으며 지판의 더 넓은 영역을 익혀 보세요.

음의 위치 찾기
지판 맵에서 네 줄의 음 이름을 확인하거나 하나의 음에 집중하세요. 학습 도구를 오가며 음 이름, 음정, 포지션의 관계를 익힐 수 있습니다.

화성 이해하기
인터랙티브 5도권에서 나란한조인 단조, 다이어토닉 코드, 자주 쓰이는 코드 진행을 살펴보세요. 조성과 코드의 관계를 시각적으로 확인할 수 있습니다.

연주 전에 튜닝하기
내장 우쿨렐레 튜너로 높은 G현을 사용하는 G–C–E–A 튜닝을 맞추세요. 줄을 자동으로 감지하거나 직접 선택할 수 있습니다. 화면에서 음이 높은지, 낮은지, 정확한지 확인하세요.

무료로 시작하기
근음 A의 학습 모드와 포지션, 5도권, A 마이너 매일 연습을 이용해 보세요. 앱 내에서 한 번 구매하면 이 앱의 모든 조성과 음을 평생 이용할 수 있습니다. 구독은 필요하지 않습니다.

마이크와 개인정보 보호
마이크 사용은 선택 사항이며 튜닝과 연습 중 피드백에 사용됩니다. 오디오는 기기 안에서 처리되며 앱이 녹음하거나 서버로 업로드하지 않습니다.

음의 위치를 알고, 코드 폼을 연결하며, 꾸준히 연습하고 싶은 우쿨렐레 연주자를 위한 앱입니다.
```
