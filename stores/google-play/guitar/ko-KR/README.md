# Guitar Fretboard Hero — Google Play — ko-KR

Fiche **한국어**, pour l'application guitare. Code de langue dans l'application : `ko` ; langue de la fiche Google Play : `ko-KR`.

Traduction de la [fiche anglaise](../en-US/README.md), avec les termes musicaux adaptés à la langue. Copier uniquement le contenu des trois blocs ci-dessous dans la console. Le nom de marque reste identique dans toutes les langues.

## Textes à copier-coller

### Nom de l'application — 21 / 30 caractères

```text
Guitar Fretboard Hero
```

### Brève description — 38 / 80 caractères

```text
매일 연습, 퀴즈, 튜너로 기타의 음, 스케일, 코드를 익혀 보세요.
```

```text

매일 연습하는 습관 만들기

모든 음 찾아보기
지판 지도에서 지판 전체의 음을 보거나 하나의 음에 집중할 수 있습니다. 여러 학습 도구를 오가며 음 이름, 음정, 포지션 사이의 관계를 이해하세요.

화성 이해하기
인터랙티브 5도권에서 나란한조인 단조, 다이어토닉 코드, 자주 쓰이는 코드 진행을 살펴보세요. 조성과 코드의 관계를 시각적으로 확인할 수 있습니다.

연주 전에 튜닝하기
내장 튜너의 자동 줄 감지를 사용하거나 줄을 직접 선택하세요. 화면에서 음이 높은지, 낮은지, 정확하게 맞는지 확인할 수 있습니다.

데모로 시작하기
라 마이너 데모를 체험해 보세요. 앱 내 일회성 구매로 모든 조성과 학습 옵션을 잠금 해제할 수 있습니다. 구독은 필요하지 않습니다.

지판을 이해하고, 포지션을 연결하며, 꾸준한 연습을 더 쉽게 이어 가고 싶은 기타 연주자를 위한 앱입니다.
```

## Textes alternatifs

[alt-text.json](alt-text.json) contient 10 textes en **한국어** : l'icône, l'image de présentation et les huit thèmes de captures, dans le même ordre que la fiche anglaise. Les identifiants techniques restent identiques ; seules les valeurs sont traduites. Chaque texte est limité à 140 caractères.

## Visuels et validation

Cette langue contient les textes uniquement. Ses captures et visuels localisés ne sont pas encore fournis. Les images existantes sont dans [en-US](../en-US/README.md) et restent en anglais. Lors de la création des visuels de cette langue, traduire aussi les captures intégrées, puis relire les textes alternatifs face aux images finales.

Le [guide Android](../../README.md) décrit les tailles et les règles communes. Les rubriques françaises de ce README sont conservées pour le validateur existant ; elles ne font pas partie du texte à publier. Les compteurs portent sur les caractères Unicode, espaces et sauts de ligne compris.

Ne générer le rapport complet `validation.json` qu'après l'ajout des images : le validateur vérifie les fichiers réellement présents et signalera les éléments obligatoires absents.
