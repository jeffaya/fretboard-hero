### Description complète — 715 / 4 000 caractères

```text
熟悉你的四弦贝斯。Bass Fretboard Hero 将引导练习、可视化学习工具、指板测验和调音器整合在一个应用中。

养成每日练习的习惯
在同一调性中完成五项练习：寻找根音、弹奏音阶、连接三和弦、练习节奏，以及探索五声音阶指型。清晰的四线谱、音名和音级标记，帮助你理解正在弹奏的内容。按自己的节奏完成步骤，并重复练习。

连接贝斯指板上的把位
探索五个五声音阶把位、大三和弦与小三和弦、转位和琶音。高亮特定音级、专注单个把位，在标准 E–A–D–G 调弦的四根弦上连接指型。

跟随麦克风反馈练习
在每日练习中开启麦克风，跟随高亮音符弹奏并获得反馈。进行音符和三和弦引导练习，并以可调速度练习节奏。你也可以关闭麦克风进行练习。

检验你的指板知识
挑战 60 秒指板测验。寻找根音、三度音和五度音，争取连续答对，并随着练习逐步熟悉更广的指板区域。

找到每个音的位置
指板图可以显示四根弦上的音名，也可以只显示某一个音。在不同学习工具之间切换，理解音名、音程与把位的联系。

理解和声关系
探索交互式五度圈、关系小调、调内和弦和常见和弦进行。直观了解调性与和弦之间的关系。

弹奏前先调音
使用内置贝斯调音器进行标准 E–A–D–G 调弦。可以自动识别琴弦，也可以手动选择。屏幕会显示音高偏高、偏低或准确。

免费开始
体验以 A 为根音的学习模式与把位、五度圈以及 A 小调每日练习。通过一次应用内购买，即可永久解锁本应用中的所有调性与音符，无需订阅。

麦克风隐私
麦克风权限为可选项，用于调音和练习时的实时反馈。音频在你的设备上处理，应用不会录制或上传音频。

为想熟悉音的位置、连接指型并坚持日常练习的贝斯手而设计。
```
